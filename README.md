# erdongsanshi.github.io

Personal academic homepage, built on the [AcaNova-X](https://github.com/yihangtao/AcaNova-X) template.

Live at: https://erdongsanshi.github.io/

## Editing your content

No build step — everything is plain HTML/CSS/JS served directly by GitHub Pages. Edit these files and push:

| What | File |
|---|---|
| Name, title, affiliation, contact links, about text | `index.html` (search for `Your Name`) |
| Profile photo | `assets/profile.jpg` |
| News items | `data/news.json` |
| Publications | `data/publications.json` |
| Honors / awards | `data/honors.json` |
| Paper thumbnails | `assets/publications/` |
| Colors / fonts | `index.html` — the `tailwind.config` block near the top |

After editing, commit and push to `main`; GitHub Pages redeploys automatically within a minute or two.
